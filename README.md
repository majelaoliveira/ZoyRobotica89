

# Zoy Robótica

Plataforma de estudos voltada para robótica educacional, programação e experimentação com Arduino.

## 🚀 Acessar a Plataforma

Clique no link abaixo para abrir o ambiente de estudos:

👉 **[Abrir plataforma](https://majelaoliveira.github.io/ZoyRobotica89/)**

## 📚 Sobre

A plataforma Zoy foi desenvolvida para apoiar o ensino de robótica de forma prática, permitindo:

- Execução de códigos
- Interação com projetos educacionais
- Aprendizado progressivo com base em experimentação

## 🛠️ Estrutura do Projeto

- `index.html` → Página principal
- `cartilha_arduino_v2.html` → Material didático
- Outros arquivos → suporte à navegação e conteúdo

## 📌 Observações

- Recomenda-se acessar via navegador atualizado
- Pode ser utilizada em ambiente educacional ou estudo individual
